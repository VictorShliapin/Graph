# 1. Общая информация
В репозитории представлен прототип программы для визуализации данных в формате LaTeX. Пользователь вводит данные в эксель, далее, выбрав оптимальную настройку графика, код воспроизводит эти данные в 
стилистике LaTeX, при этом сохраняя гибкость библиотек Python для построения изображений.

На данный момент программа поддерживает ввод до 13 зависимостей включительно, возможность показывать графики этих зависимостей в разных фигурах и/или в одной фигуре. 
Также доступна аппроксимация данных моделью линейной регрессии и нелинейной регрессией, отдельно проработаны частные случаи по типу аппроксимации полиномом или прямой через начало координат.

Для использования необходимо установить Tex.

Примеры работы кода можно посмотреть в Figure_1.pdf - Figure_4.pdf.
